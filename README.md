# Esteves & Carvalho — Landing Page Multidisciplinar

Página landing page demonstrativa desenvolvida para apresentar estruturação visual, responsividade e clareza de comunicação para escritórios de advocacia com atuação em diversas áreas do Direito.

> **Observação:** Marca, textos institucionais e dados de contato são fictícios, criados exclusivamente para fins de portfólio e demonstração técnica.

## Estrutura da Página
- **Cabeçalho e Navegação:** Acesso direto às seções e menu responsivo para dispositivos móveis.
- **Hero (Dobra Inicial):** Proposta de valor objetiva, chamadas para ação e resumo da abordagem do escritório.
- **Áreas de Atuação:** Organização em cards cobrindo diferentes frentes jurídicas em linguagem acessível.
- **Como Funciona:** Passo a passo simples do atendimento inicial ao acompanhamento.
- **Dúvidas Frequentes (FAQ):** Acordeão interativo para responder perguntas comuns.
- **Contato:** Formulário com validação inicial e feedback visual de envio.

## Tecnologias Utilizadas
- **HTML5** (estrutura semântica)
- **CSS3** (layout responsivo com Grid/Flexbox, variáveis CSS e `scroll-margin-top`)
- **JavaScript** (menu mobile, acordeão do FAQ e validação de formulário)
